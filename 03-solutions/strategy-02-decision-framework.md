# 策略二：构建决策原则库

## 核心理念

**打破"重新发明轮子"的惯性，沉淀可复用的逻辑工具。**

ENTP每次遇到新问题都要从零开始思考，Ti反复进行相似的分析工作。如果能将过往的思考成果沉淀为**可复用的决策原则**，就能大幅降低思维成本。

---

## 问题诊断

### ENTP的"重复劳动"陷阱

#### 场景对比

**第1次**：要不要跳槽？
- 分析：薪资、发展、兴趣、稳定性……
- 耗时：2周
- 建立了完整的分析框架

**第10次**：又要不要跳槽？
- 又从头分析：薪资、发展、兴趣、稳定性……
- 耗时：又是2周
- **完全忘记了之前的分析框架**

#### 核心问题

ENTP习惯于：
- ❌ 每次都"新鲜思考"
- ❌ 享受分析的过程
- ❌ 但不沉淀思考的成果
- ❌ 导致相同问题反复消耗能量

**为什么？**
- Ne喜欢新鲜感，觉得"这次不一样"
- Ti每次都想构建"更完美"的框架
- 缺乏Si的经验积累倾向

---

## 解决方案：建立个人决策体系

### 什么是决策原则库？

一套**基于你自身经验提炼的、可重复使用的决策框架和标准**。

#### 包含内容

1. **决策框架**：遇到某类问题时的思考模板
2. **判断标准**：具体的评估维度和权重
3. **经验法则**：从成败中提炼的教训
4. **SOP（标准操作流程）**：重复性任务的执行步骤

---

## 实操方法

### 第一步：识别重复性决策场景

#### 常见的ENTP重复决策场景

**职业发展类**
- 要不要跳槽？
- 要不要学习新技能？
- 要不要承接新项目？

**个人成长类**
- 要不要读这本书？
- 要不要参加这个活动？
- 要不要建立这个习惯？

**创业投资类**
- 这个项目要不要做？
- 要不要投入资源？
- 什么时候应该止损？

**日常选择类**
- 如何安排一天的优先级？
- 要不要购买这个东西？
- 如何分配时间和精力？

#### 行动

列出你过去1年中：
- 做过3次以上的相似决策
- 每次都花费大量时间思考
- 但其实思路相似

这些就是你需要建立原则的场景。

---

### 第二步：复盘Ti的分析过程

选择一个重复场景，回忆你最近一次的思考过程：

#### 复盘模板

**场景**：要不要跳槽

**我考虑了哪些因素？**
1. 薪资涨幅
2. 职业发展空间
3. 工作内容兴趣
4. 公司文化匹配
5. 通勤时间
6. 工作稳定性

**我是如何权衡的？**
- 薪资涨幅 < 20%不考虑
- 发展空间是首要因素
- 兴趣度至少要达到7/10

**我的决策逻辑是什么？**
```
IF 薪资涨幅 ≥ 30% AND 有明确发展路径
  → 认真考虑

ELSE IF 工作内容兴趣 ≥ 8/10 AND 能学到新技能
  → 认真考虑

ELSE
  → 暂不考虑
```

**最终我是怎么决定的？**
- 选择了发展空间更大的，虽然薪资涨幅只有15%
- 事后证明这个决策是对的

**下次遇到同样问题，我可以直接套用什么？**
→ 这就是你的决策原则！

---

### 第三步：提炼决策原则

#### 原则模板一：因素-权重法

**适用**：多因素综合评估的决策

**示例：跳槽决策原则**

| 因素 | 权重 | 评分标准 | 阈值 |
|------|------|---------|------|
| 职业发展 | 40% | 1-10分 | 必须≥7 |
| 学习机会 | 30% | 1-10分 | ≥6可以接受 |
| 薪资涨幅 | 20% | 百分比 | ≥20%有吸引力 |
| 工作兴趣 | 10% | 1-10分 | ≥5不排斥 |

**决策规则**：
- 加权总分 ≥ 7.5分 → 跳
- 6.5-7.5分 → 深入沟通后再决定
- < 6.5分 → 不跳

**使用方法**：
下次遇到跳槽机会，直接填表打分，30分钟内完成决策。

---

#### 原则模板二：决策树法

**适用**：有明确逻辑链条的决策

**示例：要不要学新技能**

```
新技能X

↓ 问题1：是否与当前职业发展相关？
├─ 是 → 继续
└─ 否 → ↓ 问题2：是否出于强烈个人兴趣？
         ├─ 是 → 继续
         └─ 否 → ❌ 不学

↓ 问题3：投入时间 vs 预期收益？
├─ 投入 < 50小时，且有明确应用场景 → ✅ 学
├─ 投入 > 100小时 → ↓ 问题4：是否有长期价值？
│                    ├─ 是 → ✅ 学，但分阶段投入
│                    └─ 否 → ❌ 不学
└─ 50-100小时 → 试学20小时再决定
```

**使用方法**：
遇到新技能时，按决策树逐级判断，10分钟内得出结论。

---

#### 原则模板三：经验法则

**适用**：从成败中提炼的简单规则

**示例：ENTP专用避坑法则**

基于过往失败经验：

1. **"48小时热情"法则**
   - 如果一个想法的兴奋感在48小时内衰减>50%
   - 说明不是真热情，不投入资源

2. **"第一步"测试**
   - 如果我说不出"明天第一步做什么"
   - 说明想法还不成熟，先别开始

3. **"三次重复"原则**
   - 如果一个需求/问题出现3次以上
   - 才值得投入时间构建系统性解决方案
   - （避免过度设计）

4. **"止损点"设定**
   - 任何新项目开始前，明确"什么情况下放弃"
   - 到止损点必须执行，不再纠结

5. **"S型顾问"法则**
   - 任何涉及执行细节的项目
   - 必须咨询至少1个S型人格
   - 听他们指出哪些是"实际会遇到的坑"

---

#### 原则模板四：SOP（标准操作流程）

**适用**：重复性操作任务

**示例：开始一个新项目的SOP**

```
阶段1：验证期（1周）
□ 写下核心问题（一句话）
□ 列出3个必须回答的关键问题
□ 快速调研（不超过3天）
□ 决定：继续 or 放弃

阶段2：规划期（3天）
□ 定义MVP（最小可行产品）
□ 列出第一周的具体任务（不超过5项）
□ 设定第一个里程碑（2周内可完成）
□ 明确止损点

阶段3：执行期（2周）
□ 完成MVP
□ 获得外部反馈
□ 评估：继续投入 or 调整 or 停止

阶段4：迭代 or 放弃
□ 基于反馈决策
```

**使用方法**：
每次想开始新项目，直接套用这个流程，不再重新设计。

---

### 第四步：持续沉淀与优化

#### 建立原则库的方法

**工具选择**
- Notion/Obsidian：建立知识库
- 纸质笔记本：快速记录
- Anki：记忆常用原则

**结构建议**

```
我的决策原则库/
├── 职业发展/
│   ├── 跳槽决策框架
│   ├── 技能学习决策树
│   └── 项目选择原则
├── 个人成长/
│   ├── 习惯养成SOP
│   ├── 阅读选择标准
│   └── 时间分配原则
├── 创业投资/
│   ├── 项目评估框架
│   ├── 止损原则
│   └── 资源分配标准
└── 经验法则/
    ├── ENTP避坑指南
    ├── 高效思考原则
    └── 快速决策技巧
```

#### 更新原则

**每月复盘**
- 回顾本月的重要决策
- 哪些用了原则？效果如何？
- 哪些没用原则？是否需要新建？
- 现有原则是否需要调整？

**原则迭代**
- 版本号管理（如"跳槽决策v3.0"）
- 记录修改理由
- 保留演进历史

## 典型案例应用

### 案例：要不要做这个副业项目？

#### ❌ 没有原则库的ENTP

```
看到机会 → 很兴奋 → 开始分析
→ 分析市场、成本、竞争……
→ 思考了2周 → 还是不确定
→ 又出现新信息 → 重新分析
→ 1个月过去了 → 机会窗口关闭
```

#### ✅ 使用原则库的ENTP

**直接调用"副业项���评估框架v2.0"**

```
1. 48小时热情测试 → ✅ 通过（兴奋度持续）

2. 资源匹配检查：
   - 启动资金需求 < 1万 → ✅ 符合
   - 每周投入 < 10小时 → ✅ 可接受
   - 利用现有技能 → ✅ 可以

3. 风险评估：
   - 失败最大损失 = 5000元 + 20小时
   - 在可承受范围内 → ✅

4. 执行可行性：
   - 第一步：做个落地页（2小时）
   - 第二步：发布到3个渠道测试反馈（1天）
   - 明确行动路径 → ✅

决策：✅ 做，按MVP方式启动
用时：30分钟
```

**2周后到达止损点评估**：
- 没有付费用户 → 按原则放弃
- 不再纠结，不再内耗

## 进阶技巧

### 技巧一：从别人的框架开始

不必从零构建，可以：
1. 借鉴经典决策模型（如SWOT、波士顿矩阵等）
2. 向成功的S型人格学习他们的"经验法则"
3. 阅读决策类书籍提炼框架

然后根据自己的实践迭代优化。

### 技巧二：原则的"触发器"设计

为每个原则设定明确的触发条件：

**示例**：
- **触发器**：当我对一个新想法兴奋超过2小时
- **自动调用**："48小时热情测试"原则
- **行动**：在手机上设定48小时后的提醒

### 技巧三：量化你的"思维成本节约"

记录数据：
- 使用原则前，类似决策平均耗时
- 使用原则后，平均耗时
- 节约的时间和能量

**可视化成果** → 激励你持续使用和优化

## 效果检验

### 你成功建立了决策原则库如果：

✅ 你能快速说出"我有一个原则处理这类问题"
✅ 相同类型的决策时间从几天缩短到几小时
✅ 你开始主动复盘和沉淀经验
✅ 你的决策质量更稳定（不再大起大落）
✅ 你对自己的判断更有信心

### 常见挑战

**挑战一**："每次情况都不一样，原则不适用"
- **解决**：原则是框架，不是死规则；保留灵活性，但有参考基准

**挑战二**："建立原则库好麻烦"
- **解决**：从1-2个高频场景开始；每个月只增加1个原则

**挑战三**："我忘记用原则，还是凭感觉决策"
- **解决**：设置提醒；在笔记软件首页放置"决策检查清单"

## 与其他策略的配合

- **+ 策略一（事实vs想象）**：在原则中明确"需要哪些事实才能决策"
- **+ 策略三（外部约束）**：在原则中内置时间限制
- **+ 策略四（S型人格）**：向S型学习实用的经验法则

---

## 核心要点总结

1. **不要每次都从零思考**
2. **Ti的分析成果需要沉淀**
3. **原则库 = ENTP的外部智慧大脑**
4. **降低决策成本 = 提升行动效率**

**记住**：聪明人建立系统，而不是每次都靠灵光一现。
